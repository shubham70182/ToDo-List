# ToDo List

A simple task manager to help you organize your day. Add tasks, set dates, and keep track of what you have completed.

## Features

- Add tasks with start and due dates
- Move tasks between **To Do** and **Done** by checking them off
- Double-click a task name to edit it
- Delete individual tasks or clear all completed tasks
- Save tasks in your browser using local storage

## Getting Started

1. Download or clone this repository.
2. Open `index.html` in your web browser.
3. Add a task and start organizing your work.

## Built With

- HTML
- CSS
- JavaScript

Tasks are saved in the browser where you use the app. They are not synced between browsers or devices.
